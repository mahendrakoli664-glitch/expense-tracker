==================================================
        EXPENSE TRACKER API ENDPOINTS
==================================================

BASE URL:
http://localhost:5000/api

--------------------------------------------------
1. AUTHENTICATION
--------------------------------------------------

1.1 Register User
URL: /auth/register
Method: POST

Data:
{
  "name": "Mahendra",
  "email": "mahendra@gmail.com",
  "password": "123456"
}

--------------------------------------------------

1.2 Login User
URL: /auth/login
Method: POST

Data:
{
  "email": "mahendra@gmail.com",
  "password": "123456"
}

Response:
{
  "token": "JWT_TOKEN"
}

--------------------------------------------------
2. EXPENSE MANAGEMENT (After Login)
--------------------------------------------------

2.1 Add Expense
URL: /expenses
Method: POST

Headers:
Authorization: JWT_TOKEN

Data:
{
  "title": "Food",
  "amount": 500,
  "category": "Daily Expense"
}

--------------------------------------------------

2.2 Get All Expenses
URL: /expenses
Method: GET

Headers:
Authorization: JWT_TOKEN

--------------------------------------------------

2.3 Delete Expense
URL: /expenses/:id
Method: DELETE

Example:
 /expenses/661f00000000000000

Headers:
Authorization: JWT_TOKEN

--------------------------------------------------
3. DATABASE
--------------------------------------------------

MongoDB Database:
expenseTracker

Collection:
users
expenses
